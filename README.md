#Calculadora Simples em Java 🧮
Este é um projeto de console desenvolvido em Java que realiza operações matemáticas básicas. O objetivo principal é demonstrar o uso de classes, métodos, loops (do-while), estruturas de decisão (switch-case) e tratamento de exceções.

✨ Funcionalidades
Soma: Adição de dois números decimais.

Subtração: Diferença entre dois números.

Multiplicação: Produto de dois números.

Divisão: Quociente entre dois números (com verificação básica de divisão por zero).

Loop de Execução: Permite realizar vários cálculos sem precisar reiniciar o programa.

Tratamento de Erros: Evita que o programa feche caso o usuário digite letras em vez de números.

🛠️ Tecnologias Utilizadas
Java: Linguagem de programação principal.

Scanner: Para entrada de dados via console.

Try-Catch: Para tratamento de InputMismatchException.
